# Case Study 2 – College Information Website

## Problem Statement
Design a college webpage showing institutional information, courses, facilities, admissions and contact details.

## Objectives
- Organize information into clear sections.
- Use headings, paragraphs, lists and navigation links.
- Display departments in simple cards.
- Apply CSS colors, backgrounds, borders and spacing.

## Assumptions
ABC College and its contact details are sample content.

## Algorithm
1. Create the HTML page and connect the stylesheet.
2. Add the college header and navigation.
3. Add banner and About section.
4. Add course cards and facilities list.
5. Add admissions and contact information.
6. Apply CSS and a mobile-width rule.
7. Open the page and test navigation.

## Syllabus Topics
HTML structure, elements, class attribute, anchor element, lists, CSS syntax, text color, background color, font family, font size, margin, padding, border, box model and viewport.
