# Case Study 1 – Personal Portfolio Website

## Problem Statement
Create a personal webpage to display profile, education, skills, hobbies and contact details.

## Objectives
- Structure information with HTML headings, paragraphs and lists.
- Use navigation links to move within the page.
- Style the page using CSS colors, fonts, backgrounds, borders and spacing.

## Assumptions
Alex, ABC College and the contact details are sample data. Replace them with your own details.

## Algorithm
1. Create the HTML document.
2. Add header and navigation links.
3. Create About, Education, Skills, Hobbies and Contact sections.
4. Link the CSS file.
5. Apply colors, margin, padding and borders.
6. Open index.html in a browser.

## Syllabus Topics
HTML structure, elements, class attribute, anchor element, lists, CSS syntax, text and background color, font family, font size, margin, padding, border, box model and viewport.
